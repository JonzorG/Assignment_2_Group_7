      20             :  * CPP based color structures.
      21             :  *
      22             :  * Strongly typed color storage structures with space and alpha association.
      23             :  * Will increase readability and visibility of typical mistakes when
      24             :  * working with colors.
      25             :  *
      26             :  * The storage structs can hold 4 channels (r, g, b and a).
      27             :  *
      28             :  * Usage:
      29             :  *
      30             :  * Convert a theme byte color to a linearrgb premultiplied.
      31             :  * \code{.cc}
      32             :  * ColorTheme4b theme_color;
      33             :  * ColorSceneLinear4f<eAlpha::Premultiplied> linearrgb_color =
      34             :  *     BLI_color_convert_to_scene_linear(theme_color).premultiply_alpha();
      35             :  * \endcode
      36             :  *
      37             :  * The API is structured to make most use of inlining. Most notable are space
      38             :  * conversions done via `BLI_color_convert_to*` functions.
      39             :  *
      40             :  * - Conversions between spaces (theme <=> scene linear) should always be done by
      41             :  *   invoking the `BLI_color_convert_to*` methods.
      42             :  * - Encoding colors (compressing to store colors inside a less precision storage)
      43             :  *   should be done by invoking the `encode` and `decode` methods.
      44             :  * - Changing alpha association should be done by invoking `premultiply_alpha` or
      45             :  *   `unpremultiply_alpha` methods.
      46             :  *
      47             :  * # Encoding.
      48             :  *
      49             :  * Color encoding is used to store colors with less precision as in using `uint8_t` in
      50             :  * stead of `float`. This encoding is supported for `eSpace::SceneLinear`.
      51             :  * To make this clear to the developer the `eSpace::SceneLinearByteEncoded`
      52             :  * space is added.
      53             :  *
      54             :  * # Precision
      55             :  *
      56             :  * Colors can be stored using `uint8_t` or `float` colors. The conversion
      57             :  * between the two precisions are available as methods. (`to_4b` and
      58             :  * `to_4f`).
