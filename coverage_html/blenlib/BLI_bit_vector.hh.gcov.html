       9             :  *
      10             :  * A `BitVector` is a dynamically growing contiguous arrays of bits. Its main purpose is
      11             :  * to provide a compact way to map indices to bools. It requires 8 times less memory compared to a
      12             :  * `Vector<bool>`.
      13             :  *
      14             :  * Advantages of using a bit- instead of byte-vector are:
      15             :  * - Uses less memory.
      16             :  * - Allows checking the state of many elements at the same time (8 times more bits than bytes fit
      17             :  *   into a CPU register). This can improve performance.
      18             :  *
      19             :  * The compact nature of storing bools in individual bits has some downsides that have to be kept
      20             :  * in mind:
      21             :  * - Writing to separate bits in the same int is not thread-safe. Therefore, an existing vector of
      22             :  *   bool can't easily be replaced with a bit vector, if it is written to from multiple threads.
      23             :  *   Read-only access from multiple threads is fine though.
      24             :  * - Writing individual elements is more expensive when the array is in cache already. That is
      25             :  *   because changing a bit is always a read-modify-write operation on the int the bit resides in.
      26             :  * - Reading individual elements is more expensive when the array is in cache already. That is
      27             :  *   because additional bit-wise operations have to be applied after the corresponding int is
      28             :  *   read.
      29             :  *
      30             :  * Comparison to `std::vector<bool>`:
      31             :  * - `BitVector` has an interface that is more optimized for dealing with bits.
      32             :  * - `BitVector` has an inline buffer that is used to avoid allocations when the vector is
      33             :  *   small.
      34             :  *
      35             :  * Comparison to `BLI_bitmap`:
      36             :  * - `BitVector` offers a more C++ friendly interface.
      37             :  * - `BLI_bitmap` should only be used in C code that can not use `BitVector`.
      38             :  */
