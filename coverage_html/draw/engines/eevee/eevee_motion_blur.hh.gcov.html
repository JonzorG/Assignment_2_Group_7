       5             : /** \file
       6             :  * \ingroup eevee
       7             :  *
       8             :  * Motion blur is done by accumulating scene samples over shutter time.
       9             :  * Since the number of step is discrete, quite low, and not per pixel randomized,
      10             :  * we couple this with a post processing motion blur.
      11             :  *
      12             :  * The post-fx motion blur is done in two directions, from the previous step and to the next.
      13             :  *
      14             :  * For a scene with 3 motion steps, a flat shutter curve and shutter time of 2 frame
      15             :  * centered on frame we have:
      16             :  *
      17             :  * |--------------------|--------------------|
      18             :  * -1                   0                    1  Frames
      19             :  *
      20             :  * |-------------|-------------|-------------|
      21             :  *        1             2             3         Motion steps
      22             :  *
      23             :  * |------|------|------|------|------|------|
      24             :  * 0      1      2      4      5      6      7  Time Steps
      25             :  *
      26             :  * |-------------| One motion step blurs this range.
      27             :  * -1     |     +1 Objects and geometry steps are recorded here.
      28             :  *        0 Scene is rendered here.
      29             :  *
      30             :  * Since motion step N and N+1 share one time step we reuse it to avoid an extra scene evaluation.
      31             :  *
      32             :  * Note that we have to evaluate -1 and +1 time steps before rendering so eval order is -1, +1, 0.
      33             :  * This is because all GPUBatches from the DRWCache are being free when changing a frame.
      34             :  *
      35             :  * For viewport, we only have the current and previous step data to work with. So we center the
      36             :  * blur on the current frame and extrapolate the motion.
      37             :  *
      38             :  * The Post-FX motion blur is based on:
      39             :  * "A Fast and Stable Feature-Aware Motion Blur Filter"
      40             :  * by Jean-Philippe Guertin, Morgan McGuire, Derek Nowrouzezahrai
      41             :  */
