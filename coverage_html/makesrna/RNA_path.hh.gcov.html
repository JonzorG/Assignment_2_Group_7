      37             :  * collection properties.
      38             :  *
      39             :  * The semantics around the key and index fields are specific:
      40             :  * - If a key is specified, that indicates an element of a key-based array
      41             :  *   property. If an index is *also* specified alongside the key then the index
      42             :  *   is just a fallback.
      43             :  * - If an index is specified but *not* a key, that indicates an element of an
      44             :  *   index-based array property.
      45             :  * - If neither the key nor index are specified, that indicates a property as a
      46             :  *   whole.
      47             :  *

      58             :  * magic value to mean things like "all array elements". However, magic values

      60             :  * unspecified. Unspecified indices can then be converted to a negative magic
