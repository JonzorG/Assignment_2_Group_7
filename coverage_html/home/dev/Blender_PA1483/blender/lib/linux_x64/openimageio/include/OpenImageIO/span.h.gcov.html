     428             : // Explanation about make_span/make_cspan:
     429             : //
     430             : // If you want to write a function that takes a span of a known type, you can
     431             : // do so and call it with any of the kinds of containers that you could
     432             : // construct a span from. For example:
     433             : //
     434             : //     void myfunc(span<float> x) { ... }
     435             : //
     436             : //     std::vector<float> v;
     437             : //     myfunc(v);   // OK
     438             : //     float arr[10];
     439             : //     myfunc(arr); // OK
     440             : //
     441             : // But if you want to write a templated function that takes a span of the
     442             : // templated type, you can't do that. For example:
     443             : //
     444             : //     template<typename T>
     445             : //     void myfunc(span<T> x) { ... }
     446             : //
     447             : //     std::vector<float> v;
     448             : //     myfunc(v);   // ERROR
     449             : //     float arr[10];
     450             : //     myfunc(arr); // ERROR
     451             : //
     452             : // The problem is that span<T> is not span<float>, so the compiler can't
     453             : // deduce the template type. You can't even explicitly cast it:
     454             : //
     455             : //     myfunc(span<float>(v));   // ERROR
     456             : //     myfunc(span<float>(arr)); // ERROR
     457             : //
     458             : // The solution is to write `make_span()` and `make_cspan()` function
     459             : // templates that will deduce the template type and return the correct kind of
     460             : // span. So we do so for the particular cases of std::vector<T> and T[N]
     461             : // arrays. This is not a complete solution, but it's enough for our purposes.
