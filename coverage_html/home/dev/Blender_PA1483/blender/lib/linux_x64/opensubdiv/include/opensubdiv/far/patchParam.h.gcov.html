      22             : /// Topological refinement splits coarse mesh faces into refined faces.
      23             : ///
      24             : /// This patch parameterzation describes the relationship between one

      30             : ///
      31             : /// The U,V and refinement level parameters describe the scale and offset
      32             : /// needed to map a location on the patch between levels of refinement.
      33             : /// The encoding of these values exploits the quad-tree organization of
      34             : /// the faces produced by subdivision. We encode the U,V origin of the
      35             : /// patch using two 10-bit integer values and the refinement level as
      36             : /// a 4-bit integer. This is sufficient to represent up through 10 levels

      38             : ///

      40             : /// irregular coarse faces. We adopt a convention similar to Ptex texture
      41             : /// mapping and define the parameterization for these faces in terms of the
      42             : /// regular faces resulting from the first topological splitting of the
      43             : /// irregular coarse face.
      44             : ///

      46             : /// parametric patch representing a refined face, we also need to know which
      47             : /// edges of the patch are interpolated boundaries. These edges are encoded

      50             : ///
