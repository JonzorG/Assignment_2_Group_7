      93             :  *
      94             :  * Storing corner indices (instead of vertex indices) gives more flexibility for accessing mesh
      95             :  * data stored per-corner, though it does often add an extra level of indirection. The index of the

      99             :  * Examples:

     104             :  *   positions[corner_verts[tri[1]]],
     105             :  *   positions[corner_verts[tri[2]]],
     106             :  * };
     107             :  *
