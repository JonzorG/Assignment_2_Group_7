      17             :  * `def bake(scene, object, pass_type, object_id, pixel_array, pixels_num, depth, result)`

      20             :  * - pass_type: pass to render (string, e.g., "COMBINED", "AO", "NORMAL", ...)

      22             :  * - pixel_array: list of primitive ids and barycentric coordinates to
      23             :  *   `bake(Python object, see bake_pixel)`.
      24             :  * - pixels_num: size of pixel_array, number of pixels to bake `int`.
      25             :  * - depth: depth of pixels to return (`int`, assuming always 4 now).
      26             :  * - result: array to be populated by the engine (`float` array, #PyLong_AsVoidPtr).
      27             :  *
      28             :  * \note Normals are expected to be in World Space and in the +X, +Y, +Z orientation.
      29             :  *
      30             :  * \subsection bake_pixel BakePixel data structure
      31             :  *
      32             :  * pixel_array is a Python object storing BakePixel elements:
      33             :  *
      34             :  * \code{.c}
      35             :  * struct BakePixel {
      36             :  *     int primitive_id, object_id;
      37             :  *     float uv[2];
      38             :  *     float du_dx, du_dy;
      39             :  *     float dv_dx, dv_dy;
      40             :  * };
      41             :  * \endcode
      42             :  *
      43             :  * In python you have access to:
      44             :  * - `primitive_id`, `object_id`, `uv`, `du_dx`, `du_dy`, `next`.
      45             :  * - `next()` is a function that returns the next #BakePixel in the array.
      46             :  *
      47             :  * \note Pixels that should not be baked have `primitive_id == -1`.
      48             :  *
