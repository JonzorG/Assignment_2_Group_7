       8             :  * Baker from the Multires
       9             :  * =======================
      10             :  *
      11             :  * This file is an implementation of a special baking mode which bakes data (normals, displacement)
      12             :  * from the highest multi-resolution level to the current viewport subdivision level.
      13             :  *
      14             :  * The initial historical reasoning for having such baker was:
      15             :  * - Lower memory footprint than the regular baker.
      16             :  * - Performance (due to lower overhead compared to the regular baker at that time).
      17             :  * - Ease of use: no need to have explicit object to define cage.
      18             :  * Over the time some of these points became less relevant, but the ease of use is still there.
      19             :  *
      20             :  * The general idea of the algorithm is pretty simple:
      21             :  * - Rasterize UV of the mesh at the bake level.
      22             :  * - For every UV pixel that is rasterized, figure out attributes on the bake level mesh and the
      23             :  *   highest subdivision multi-resolution level (such as normal, position).
      24             :  * - Do the math (like convert normal to the tangent space),
      25             :  * - Write pixel to the image.
      26             :  *
      27             :  * SubdivCCG is used to access attributes at the highest multi-resolution subdivision level.
      28             :  *
      29             :  * The core rasterization logic works on triangles and those triangles are fed to the rasterizer in
      30             :  * a way that makes it easy to sample attributes in the SubdivCCG:
      31             :  * - Triangle knows which CCG index it corresponds to (triangle never covers multiple grids).
      32             :  * - It also knows UV coordinates of its vertices within that grid.
      33             :  *
      34             :  * The way triangles are calculated when baking to the base level is pretty straightforward:
      35             :  * - Triangles are actually calculated from a quad.
      36             :  * - Quad vertices align with the grid vertices.
      37             :  * This means that the top level loop iterates over face corners, calculates quad for the grids,
      38             :  * and passes it to the triangle rasterization.
      39             :  *
      40             :  * When baking to a non-0 subdivision level a special trick is used to know grid index and its UV
      41             :  * coordinates in the base mesh: for every loop in the bake-level mesh the algorithm calculates
      42             :  * this information using subdiv's foreach logic. This assumes that the bake level mesh is
      43             :  * calculated using the same foreach logic.
      44             :  *
      45             :  * Use low resolution mesh
      46             :  * -----------------------
      47             :  *
      48             :  * This is a special option for the displacement baker.
      49             :  *
      50             :  * When it is ON: displacement is calculated between the multi-resolution at the highest
      51             :  * subdivision level and the bake-level mesh.
      52             :  *
      53             :  * When it is OFF: displacement is calculated between the multi-resolution at the highest
      54             :  * subdivision level and a mesh which is created from the bake level mesh by subdividing it further
      55             :  * to reach the same subdivision level of the highest multi-resolution level. Additionally, the
      56             :  * texture UV, and UV tangents are used from this "special" mesh.
      57             :  *
      58             :  * Possible optimizations
      59             :  * ----------------------
      60             :  *
      61             :  * - Reuse mesh from the viewport as bake-level mesh.
      62             :  *
      63             :  *   It could be a bit challenging since mesh could be in sculpt mode, where it has own SubdivCCG
      64             :  *   and does not have UV map on the subdivided state. Additionally, it will make it harder to
      65             :  *   calculate tangent space as well.
      66             :  */
